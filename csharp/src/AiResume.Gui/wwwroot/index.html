使用说明

1. 勾选要守护的项目。续跑模型默认跟随该会话最近使用的模型(↺),也可以逐个改选;多个项目可以共用一个模型,共用的项目受同一份额度约束。

2. 点「布防」。会话被用量上限打断后,额度一恢复就按队列逐个用原会话续跑;每个项目启动前都重新核验额度。

3. 会话还开在 Claude Code 里时不会被重复续跑:额度恢复后先交给客户端自己继续,仍没继续时飞书提醒你(可在原会话或手机远程里继续)。

4. 一次性模式下每个项目最多续一次,全部完成后自动解除;连续模式(工具菜单)每次被打断都会续跑。
